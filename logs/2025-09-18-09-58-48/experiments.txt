Compact Attention: Experimental Results and Analysis

1. Experimental Setup
   1.1 Hardware Configuration:
   - Single H800 GPU
   - ThunderKittens framework implementation
   
   1.2 Test Models:
   - Wan2.1 (14B parameters): 81 frames at 768×1280 resolution
   - Hunyuan: 129 frames at 768×1280 resolution
   
   1.3 Evaluation Metrics:
   - Quality: SSIM, PSNR, MSE
   - VBench metrics: Subject Consistency, Background Consistency, Aesthetic Quality
   - Text-Video Alignment: CLIPSIM, CLIP-Temp (CLIP-T)
   - Performance: Attention sparsity rate, attention latency

2. Baseline Comparisons
   2.1 Compared Methods:
   - Full Attention (baseline)
   - STA (Sliding Tile Attention) - spatio-temporal locality
   - Sparse VideoGen - static pattern
   - Sparge Attention - dynamic pattern

5. Ablation Studies
   5.1 Sparse Pattern Effectiveness:
   - Dual Attention Windows increase cross pattern sparsity by ~10%
   - Frame-group-wise patterns contribute additional ~3% improvement
   - Overall sparsity improvement: 9.8% with τ=0.9, λ=0.011

6. Sensitivity Analysis
   6.1 Recall Threshold Impact:
   - Higher recall thresholds → lower sparsity but better quality
   - Lower recall thresholds → higher sparsity but potential quality loss
   - Sparsity converges to upper bound determined by cost constraints

   6.2 Early Denoising Sensitivity:
   - 1.02dB PSNR drop when full attention applied only in final 15 steps vs first 15
   - Critical to maintain full attention in early timesteps (first 15 denoising steps)
   - Sparse attention safe for later stages without significant quality loss

7. Robustness Analysis
   7.1 Input Stability:
   - Pattern similarity >94.4% across different seeds
   - Computational demands nearly identical across different prompts
   - Consistent performance with narrow interquartile range

   7.2 Parameter Sensitivity:
   - (τ=0.9, λ=0.011) configuration shows highest median PSNR
   - Limited variance across stochastic/semantic input perturbations

8. Visual Quality Assessment
   - Compact Attention maintains superior visual quality at higher sparsity levels
   - Outperforms STA, Sparse VideoGen, and Sparge Attention in PSNR/MSE metrics
   - Minimal perceptual degradation despite significant computational savings
